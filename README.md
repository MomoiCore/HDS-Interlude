# HDS Interlude / 幕间系统

> 聊天在幕前发生，生活在幕间继续。

HDS（Hyperrealistic Dialogue System）Interlude 旨在创造面向一对一线上聊天关系的、高度独立的超拟真对话对象，并为 AI 拟真对话提供一种新的思路框架。
它基于koishi开发，作为koishi插件存在。

幕间系统在尝试为拟真对话提供一条不同于传统对话 Bot 的路径：
不将消息视为对用户输入的即时回应，而是将其视作角色所处现实中的事件。

在幕间，角色的生活会随对话同步推进：
它拥有正在发生的日常、人际关系、行动、动机、情绪与时间线。
它可以因为忙碌而未读，因为犹豫而延迟回复，也可能因为一段关系的变化，主动改变原本的安排。

因此，HDS Interlude 不再将大量提示词、人设条目与发言规则作为维持拟人感的主要手段。它更关注如何让角色所处的现实足够可信，以至于它的每一次回答、沉默、回避与靠近，都成为有原因的选择。

## 你定义过去，你们共同经历现在

幕间系统允许你定义一个角色与其世界的起点：

- **角色**：身份、关系、语言习惯、价值观、行为边界与过往经历
- **世界**：地点、时间、配角、社会关系、日常安排与世界规则
- **叙事**：日常或戏剧化、低或高事件密度、关系发展节奏
- **关系**：对话对象和你/世界配角之间的初始距离与互动边界

但这次设定不是静态人设卡。

当对话开始，角色、关系与世界都会在时间流逝和事件积累中发生变化。
你定义的只是一种过去；现在与未来，则由你、角色，以及角色所处的世界共同书写。

> HDS Interlude 仍处于 Beta 阶段。
> 当前最新的 1.0 Beta 版本将单个会话限制为最多 50 轮；
> 随着开发推进，记忆、叙事压缩与长期会话能力将逐步完善。
>
> 它目前正在探索第一个问题：
> 当角色拥有自己的生活时，聊天会变成什么？
